# AXIOMA POS · Programa para Windows y Mac

Aquí solo se publican los **instaladores** del programa de escritorio de
[AXIOMA POS](https://puntoventaaxioma.mx) y los archivos que usa su
actualizador automático. El código fuente no está en este repositorio.

**Descarga:** usa siempre el botón de *Mi plan* dentro de AXIOMA o la página
oficial. No instales copias que te hayan enviado por otro medio.

- **Mac:** instaladores firmados y notarizados por Apple.
- **Windows:** durante el piloto el instalador no está firmado. Windows mostrará
  «Windows protegió tu PC» → *Más información* → *Ejecutar de todas formas*.

¿Dudas o problemas? Escríbenos desde AXIOMA o a soporte de AXIOMA POS.
